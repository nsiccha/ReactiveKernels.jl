## Fit placement: bind-time host (transformed-data mirror)

Eigen/nullspace/quantile/`\` are inexpressible in the kernel graph
(the peer's own feasibility doubt), so a literal traced fit is
infeasible. The fit runs at BIND (host, full LAPACK) and materializes
basis COLUMNS as bound vectors; the graph sees only vector ops + the
summand. Precedents: `LevelMap` values fill at bind under the same
joint-plan decision, and SB computes bases in transformed data (host).
The decision's core demand holds: the thin layer computes from raw
columns — no BRM-precomputed matrix crosses. Replay/frozen-fit is
slice-2 (density+gradient-only now); fit/apply stay split (verbatim
port) so slice-2 reuses them.
