- Every contract delta is flagged to the peer before its implementation.

## Key Decisions
1. **Capture-time macro, lowering with data names (REVISED 2026-09-18).** `@rkppl` captures its block AST into an `RKPPLModel` value (StanBlocks `SlicModel` shape); lowering runs via `lower_rkppl(ast, data_names)::StructuralPlan` at bind/call time, then `bind_data`. REVISION REASON: response-vs-parameter classification is impossible data-free — `theta ~ Normal(mu, tau)` (param) and `y ~ Normal(theta, s)` (response) are shape-identical (eight-schools indistinguishability), so only data names decide. The "no text seam, no parser" rationale stands (AST in, plan out); LNNs keep error sites at user code. The BRM emitter calls `lower_rkppl` with its known data names, then binds. `@rkppl data body` evaluates caller-scope data and lowers+binds immediately (StanBlocks mirror).
2. **Single-struct two-state IR, not two types.** `StructuralPlan` gains an unbound state (empty `columns`) plus `bind_data(plan, columns; roles)`; validation splits into `validate_structure` (always) and data checks at bind (column existence incl. `Symbol` evidence bounds, `n_obs` consistency, eltype admission). Rejected: a separate `UnboundPlan` type (struct duplication, dual validators, dual generator paths). The generator takes bound plans only and fails loudly otherwise; the query surface is unchanged.
3. **Surface vocabulary is `Distributions.jl` constructors (REVISED 2026-09-18: user surface ruling — no BRM-specific syntax, StanBlocks-close).** `sigma ~ Exponential(1)`, `y .~ Normal.(mu, sigma)`; no `*_lpdf`/`*_lpmf` names, no `std_normal`/`inv_gamma`, no `lower=` keywords. The `@ppl`-precedent `positive()` combinator is DEAD (uninvented here); half-Normal/half-Cauchy is `truncated(Normal(0, s), 0, Inf)` (pure Distributions.jl). Evidence/weights rule (REVISED per user 12:28 — Distributions.jl objects wherever they exist, julianic object-first shape for the rest): `truncated.(Normal.(mu,s), lo, hi)` / `censored.(...)` verbatim; `weighted.(Normal.(mu,s), w)` and `interval_censored.(Normal.(mu,s), hi)` object-first (the family-first StanBlocks-HOF shapes are dead — halfway hybrid); `HalfNormal(s)`/`HalfCauchy(s)` direct (lowering to the `:positive` override); `Flat()` Turing-style improper (lowercase `flat()` rejected). Links are explicit wrappers: `Bernoulli.(logistic.(eta))`, `Poisson.(exp.(eta))` (the Turing-idiomatic julianic spellings; bare `Bernoulli.(p)`/`Poisson.(mu)` fail closed). Broadcasting is EXPLICIT — gate resolved 2026-09-18 (user: implied broadcast forbidden). Vector math is dotted (`mu = a .+ b .* x` — undotted scalar/vector `+` is a `MethodError` in Julia too); vector responses use the Turing dotted tilde (`y .~ Normal.(mu, sigma)`); `~` is scalar-only; the old implicit spellings fail closed naming the dotted fix. Remaining implicitness (tracked, needs the `@plate` decision + IR growth): `.~` still desugars to the IR likelihood-plate without showing the plate, and `c[g]` is per-cell indexing without an explicit cell.
4. **Predictor/term coverage via plain-expression affine analysis (REVISED 2026-09-18: formula sketch DEAD — BRM-flavored, not StanBlocks).** Predictor definitions are plain deterministic assignments consumed as likelihood locations (`mu = a .+ b .* x .+ c[g] .+ o`); lowering decomposes the affine sum: bare coefficient → InterceptTerm, `coef .* data` → ContinuousTerm, `coefvec[data]` → FactorTerm (treatment, ref=1 default), bare data → OffsetTerm. Anything else (literals, data*data, coef*coef, nested calls) fails closed with the fix. Coefficient priors are `coef ~ Normal(literal, literal)` statements recovered by name (`PopulationPrior(predictor, addressee)`); a missing coefficient prior defaults to Normal(0,1) (emitter convention). The D2 role macros (`@predictor`/`@weights`/`@submodel`/`@use`) are DEAD by user decision 0lg3bfg; submodel composition follows StanBlocks (`y ~ sm(...)` use-site, locked by user comment) and needs composition semantics beyond slice 1.
5. **Plate emission with the two known gotchas handled**, plus a U0 probe for in-graph HAVE-route selection (`bernoulli` logit route, `poisson` log-rate route — keyword form or equivalent). Fallback if the probe fails: Bernoulli keeps its current hand-fused logit form as a documented exception; gaussian/poisson plate regardless (their routes are positional).
6. **SUPERSEDED by Decision 7 (2026-09-18): spelling-based routing was magic (naming a subexpression flipped legality; definitions changed meaning by distant use; Julia-equivalent spellings diverged).** Kept for the record: definitions routed vector iff dotted/broadcast or referencing another vector definition; likelihood-location roots were excluded from vector routing; chaining over derived was rejected.
7. **Inline lowering with Julia-truthful shapes (2026-09-18, explicit-broadcast rework).** `=` binds values with Julia semantics — no routing table. Predictor locations inline deterministic structure (scalars always; vectors holding coefficient candidates), canonicalize Julia-valid undotted scalar-array ops (`*`, `/`, unary `-`) to dotted form, and recover affine terms; Julia-invalid vector combinations fail naming the dotted fix. Anonymous non-affine vector substructure auto-extracts to `_rkppl_synth_N` derived locals (fresh-name generation dodges user definitions), so factored and un-factored programs lower to identical plans. Coefficients are addressable only inside predictor structure (codegen truth: they live in coef views). Rejections happen only for genuinely unrepresentable programs (non-affine locations, unknown functions, degenerate scalar structure). Contract/IR/generator unchanged. Follow-ups: fold data-only assignments at bind (bound= recipes), scalar-offset IR terms, data-only-assignment codegen folding.
6. **Column roles: peer-approved six-vocab (implemented in U2).** `bind_data` accepts `roles::Dict{Symbol,Symbol}` (`:response`/`:predictor`/`:weight`/`:evidence`/`:cv`/`:data`); roles are optional at bind with inferred defaults (precedence response > evidence > weight > predictor > data; term columns are the only `:predictor` source) and explicit roles overriding. The peer added `:evidence` for bound columns (structural, travels with its response under CV like weights) and approved this shape before unit 2.

## Recommended Approach
Probe first, then behavior-preserving retarget, then structural split, then surface: U0 (HAVE-route probe) → U1 (plate emission; corpus pins it) → U2 (unbound/bind split; peer-approved roles shape) → U3 (macro + lowering + submodels + `@plate`/`@scan`). Rationale: the riskiest unknown (U0) is answered before any rewrite; U1 locks behavior while the generator input is still stable; U2's churn lands on plate-based emission; U3's surface risk comes last, when everything underneath is pinned. Each unit is independently committable and testable; peer gates (delta flags, corpus runs) sit between units.
