Distribution kernels ​

ReactiveKernelsDistributionKernels exports the DistributionKernelSources module. Its kernel objects expose named endpoints such as logpdf, logcdf and quantile; the available endpoints depend on the distribution. These are ReactiveKernels graphs, with explicit ports for observations and parameters.

Kernel objects ​

Import the required object and call an endpoint inside an authored graph. The prepared result below is checked against Distributions at the same inputs.

julia
using ReactiveKernels
using ReactiveKernelsDistributionKernels.DistributionKernelSources: normal
using Distributions: Normal, logpdf

@kernel normal_density(x, location, scale) = begin
    density = normal(; location, scale).logpdf(x)
    return density
end
run_density = prepare(normal_density)
value = run_density(0.5, 0.0, 2.0)
reference = logpdf(Normal(0.0, 2.0), 0.5)
@assert value ≈ reference
(; value, reference)

(value = -1.643335713764618, reference = -1.643335713764618)

The endpoint is part of the enclosing graph, so preparation can select its inputs and outputs using the same boundary rules as an authored expression. The graph guide explains that selection. The conditional-latent example uses a hidden Markov density and its corresponding latent query.

State-path draws ​

ReactiveKernelsDistributionKernels.DistributionKernelSources.draw_hmm_states Method
julia
draw_hmm_states(rng, posterior) -> Vector{Int}
draw_hmm_states!(rng, path, posterior) -> path

One exact draw of a hidden Markov law's state path from its posterior, the value of the law's state-posterior twin (normal_hmm_state_posterior and so on). The last state is drawn from its filtered probabilities, then each earlier state given its successor, from the filtered probabilities weighed by the move into that successor (forward filtering, backward sampling). Only rng supplies randomness, so a seeded rng reproduces the path. Throws an ArgumentError when the observations are impossible under every path.
