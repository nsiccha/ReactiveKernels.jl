Distribution kernels ​

ReactiveKernelsDistributionKernels exports the DistributionKernelSources module. Its kernel objects expose named endpoints such as logpdf, logcdf and quantile; the available endpoints depend on the distribution. These are ReactiveKernels graphs, with explicit ports for observations and parameters.

Kernel objects ​

Import the required object and call an endpoint inside an authored graph. The prepared result below is checked against Distributions at the same inputs.

julia
using ReactiveKernels
using ReactiveKernelsDistributionKernels.DistributionKernelSources: normal
using Distributions: Normal, logpdf

@kernel normal_density(x, location, scale) = begin
    density = normal(; location, scale).logpdf(x)
    return density
end
run_density = prepare(normal_density)
value = run_density(0.5, 0.0, 2.0)
reference = logpdf(Normal(0.0, 2.0), 0.5)
@assert value ≈ reference
(; value, reference)

(value = -1.643335713764618, reference = -1.643335713764618)

The endpoint is part of the enclosing graph, so preparation can select its inputs and outputs using the same boundary rules as an authored expression. The graph guide explains that selection. The conditional-latent example uses a hidden Markov density and its corresponding latent query.

Law parameters ​

Each law's docstring, listed under "Law reference" below, opens with its call signature, such as gamma(shape, rate). A positional construction binds the parameters in that order. A named construction binds any port the law lists under "Named bindings", which selects another parameterization: here the gamma law by its scale. Outside a kernel, a prepared endpoint takes the parameters first and then the endpoint's own argument.

julia
using ReactiveKernelsDistributionKernels.DistributionKernelSources: gamma
using Distributions: Gamma

@kernel gamma_by_rate(x, shape, rate) = gamma(shape, rate).logpdf(x)
@kernel gamma_by_scale(x, shape, θ) = gamma(; shape, scale = θ).logpdf(x)
by_rate = prepare(gamma_by_rate)(1.2, 2.5, 1.5)
by_scale = prepare(gamma_by_scale)(1.2, 2.5, 1 / 1.5)
outside = prepare(gamma.logpdf)(2.5, 1.5, 1.2)
reference = logpdf(Gamma(2.5, 1 / 1.5), 1.2)
@assert by_rate ≈ by_scale ≈ outside ≈ reference
(; by_rate, by_scale, outside, reference)

(by_rate = -0.797537765011576, by_scale = -0.797537765011576, outside = -0.797537765011576, reference = -0.7975377650115762)

In the REPL, ?DistributionKernelSources.gamma or @doc DistributionKernelSources.gamma shows the docstring. Base.Docs.doc(gamma) takes the value instead of the name, so it describes the object's internal type.

ReactiveKernelsDistributionKernels.DistributionKernelSources.ar1 Constant
julia
ar1(μ, ϕ, scale)

Stationary first-order autoregressive normal law of a series x: x[t] - μ = ϕ * (x[t - 1] - μ) + scale * ε[t] with standard normal ε, and x[1] drawn from the stationary law, of standard deviation scale / sqrt(1 - ϕ^2). scale > 0 is the innovation standard deviation, and logpdf is -Inf unless abs(ϕ) < 1. The same law as Distributions.MvNormal with mean μ everywhere and covariance scale^2 * ϕ^abs(i - j) / (1 - ϕ^2).

Endpoints: logpdf(x).

bernoulli(p)

Bernoulli law of a Bool outcome with success probability p: the same law as Distributions.Bernoulli(p).

Named bindings: logit, the log-odds log(p / (1 - p)), in place of p, as in bernoulli(; logit = η).logpdf(y); it stays exact where p would round to 0 or 1.

Endpoints: logpdf(observed), cdf(observed), quantile(q).

location_scale(standard)

Location-scale family of a parameter-free standard law. Binding the standard law, outside a kernel, gives the law of location + scale * z for z drawn from standard, with parameters (location, scale) and scale > 0. normal, cauchy, laplace and logistic are location_scale(standard_normal) and its siblings, bound once at top level; a model's own family is bound the same way, as in const my_law = location_scale(my_standard).

Endpoints: logpdf(x), cdf(x), ccdf(x), logcdf(x), logccdf(x), quantile(p), and standardized(x), which is (x - location) / scale.

Multivariate normal law of a vector x with mean μ. zero_inflated_binomial(n, p, zi)

Zero-inflated binomial law of a count: a structural zero with probability zi, otherwise a binomial count over n trials with success probability p. The same law as Distributions.MixtureModel([Distributions.Dirac(0), Distributions.Binomial(n, p)], [zi, 1 - zi]).

ReactiveKernelsDistributionKernels.DistributionKernelSources.draw_hmm_states Method
julia
draw_hmm_states(rng, posterior) -> Vector{Int}
draw_hmm_states!(rng, path, posterior) -> path

One exact draw of a hidden Markov law's state path from its posterior, the value of the law's state-posterior twin (normal_hmm_state_posterior and so on). The last state is drawn from its filtered probabilities, then each earlier state given its successor, from the filtered probabilities weighed by the move into that successor (forward filtering, backward sampling). Only rng supplies randomness, so a seeded rng reproduces the path. Throws an ArgumentError when the observations are impossible under every path.
