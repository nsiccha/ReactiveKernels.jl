JAX translations ​

Companion to JAX source: statistics reductions and package mappings. The Julia that prepare_data runs is in JAX host preparation.

Factorizations and triangular solves ​

For a dense Float32 or Float64 matrix A, use F = qr(A), R = F.R and Q = Matrix(F.Q). Machine integers promote to floating point as in Julia. The two projections share one unpivoted QR factorization. For an m × n matrix, Q has min(m, n) orthonormal columns and Q * R reconstructs A. On a tall matrix the explicit Matrix conversion selects thin Q from Julia's implicit square operator. QR signs follow the numerical library. For a full-column-rank matrix, make the diagonal of R positive by multiplying each column of Q and the corresponding row of R by the sign of that diagonal entry. JAX can differentiate both factors on tall, full-column-rank inputs. On Julia 1.10.12, Enzyme 0.13.221 fails to differentiate the native signed factor sum in LinearAlgebra.getproperty. A device cell with a padded matrix of variable size cannot yet export its QR.

rk_cholesky_lower(A) reads only the lower triangle, including when unused upper entries are nonfinite. It checks for square input and positive pivots, with runtime checks masked by the enclosing branch or plate. Empty factors and padded leading square blocks are supported. diag(L) reads the diagonal. Data-only factorizations and solves run in prepare_data. Arithmetic follows the module's float_type.

Use LowerTriangular(A) \ b or UpperTriangular(A) \ b with a square matrix and a vector or matrix right-hand side. Only the selected triangle contributes. norm(v) computes a real vector's Euclidean norm with scaling for large and small magnitudes.

Symmetric eigendecomposition ​

F = eigen(Symmetric(A)) exports one symmetric eigendecomposition of a dense real matrix. F.values contains ascending eigenvalues and the columns of F.vectors are orthonormal. Use eigvals(Symmetric(A)) for eigenvalues alone. The default and :U use the upper triangle, and :L uses the lower triangle. When comparing Julia and JAX, compare reconstructed matrices or eigenspace projectors because signs and bases within repeated eigenspaces can differ. The RK-owned rk_symmetric_eigvals and rk_symmetric_eigvecs use the upper triangle and retain their authored derivative rules. A dynamically padded matrix cannot be passed to the eigensolver because the padding would contribute additional eigenvalues.

Index of a vector maximum ​

Use grid[argmax(signal)] to select the grid entry at the first maximum of a nonempty real vector. argmax returns a one-based integer index in both device code and host preparation. The grid can be in any order. For example, signal = [1.0, 4.0, 4.0] selects the second grid entry. As in Julia, the first NaN wins and positive zero sorts above negative zero. An evaluated argmax on an empty vector raises an error.

Statistics reductions ​

With Statistics loaded (ReactiveKernelsStatisticsExt, RK 0.1.262), mean(x), mean(f, x), var(x) and std(x) translate, with the keywords dims (one integer known while JAX traces, or :), and for var and std also corrected (a literal true or false) and mean. Each is the core sum, length and size translation it composes, sum(x) / length(x) and sum(abs2.(x .- m)) / (n - corrected), so a padded row or a dims reduction reads only its valid entries and prepare_data takes NumPy's spelling. Over dims the reduced axis keeps length one, as in Julia. An empty argument, or one entry with corrected, gives Julia's NaN. Before, Statistics' own methods, which branch, were refused as "the function _mean has loops or branches".

Package translations ​

A package extension can map its own callable during source emission. Julia execution is unchanged; ordinary jax.grad differentiates the emitted primal without a registered derivative rule.

Use ReactiveKernels._jax_elementwise(::typeof(f)) for scalar calls and f.(xs). Return a Python callable name, name => source defining a module-level helper, or nothing for fallback translation. This does not register ordinary array calls: Julia's exp(A) is a matrix exponential; exp.(A) applies scalar exponentials.

For a positional whole-function call, including an array-valued helper, define _jax_function_call(ctx::_JaxContext, ::typeof(my_function), args::Vector{_PyVal}). Qualify RK names with ReactiveKernels, as in the executable example below.

These underscored names form the package extension interface. The context and vector annotations make the method more specific than RK's generic method. Selection precedes recorded/provider source and lowered-code translation, but follows applicable scalar/elementwise mappings. This hook registers positional calls, not keyword handling.

Each args[i] describes an argument: code is its Python expression, T its Julia type. Parenthesize expressions when composing operators. Return a _PyVal, not a string or nothing; call _jax_traceable_or_lowered(ctx, f, args) for the generic hook's source fallback.

_jax_result(f, args, expression) infers the native result type from f and the argument types, preserving matrix rank for subsequent multiplication. The expression must implement that native result and shape. Shapes and numerical inputs remain runtime expressions, not sampled data. For elementwise whole-array calls preserving the arrays' axes, _jax_elementwise_result(f, args, expression) additionally carries padded-axis metadata.

For changed shape or ragged structure, the full constructor is _PyVal(code, T, static, extent, limit, padded). Short constructors default static=false, extent="", limit="", and padded=0.

FieldMeaning
static::BoolKnown as a Python value while JAX traces; it can decide Python control flow. A JAX array is not static merely because its inputs are constants.
extent::StringValid length of a padded row, or lengths of a ragged collection; empty for an unpadded value.
limit::StringStatic upper-bound expression of a data-dependent integer, for loops and allocation; empty when absent.
padded::IntBitmask of padded axes (bit k-1 for axis k), implicit for a vector; for a tuple, of its fields with a length.

_jax_result carries an input extent to an array result without deriving new lengths or padding axes. Operations must account for padding and return their actual result metadata: copying input metadata cannot describe arbitrary reductions, reshapes or matrix functions. The matrix-exponential example takes an ordinary dense matrix, not a padded ragged row.

Host preparation and helpers ​

The hook also serves prepare_data, where ctx.host !== nothing. RK rewrites jnp.* to np.*, jsp.* to ssp.* (SciPy special functions), and jax.scipy.linalg.* to scipy.linalg.*. _jax_result uses these host spellings for all-static operands too, keeping shape/literal arithmetic usable in Python guards. Branch on ctx.host if different host mathematics is needed. Leftover device-only constructs (jax.lax, .at[...]) cannot form host preparation: the recipe stays on device or is reported untranslated, according to the preparation boundary.

Define Python helpers with _jax_helper!(ctx, name, source) and use its returned name. It emits each name once; host mode emits a NumPy twin with an _np suffix. Names must be unique across the module. For all-static operands in device mode, use _host_helper!(ctx, name, source) when a host spelling exists: _jax_result cannot discover JAX calls inside separate helper bodies. _jax_elementwise pairs select automatically. Custom helpers must not mutate inputs; RK cannot enforce ownership on arbitrary Python text or translate independently written derivatives.

Executable scalar and matrix example ​

This file defines owned helpers, mappings and kernels. The loop in triple requires its mapping for translation; matrix exponential demonstrates whole-array mathematics distinct from elementwise mapping.

module JAXTranslationExample

using ReactiveKernels
using LinearAlgebra
const RK = ReactiveKernels

# A package owns these Julia functions; its RK extension owns the mappings.
function triple(x)
    result = zero(x)
    for _ in 1:3
        result += x
    end
    result
end

RK._jax_elementwise(::typeof(triple)) = "_example_triple" => """
def _example_triple(x):
    return 3 * x
"""

# An ordinary call on an array has its own translation. Here its mathematics
# happens to be elementwise too, so preserve the input's padded axes as well.
function RK._jax_function_call(ctx::RK._JaxContext, ::typeof(triple),
                               args::Vector{RK._PyVal})
    RK._jax_elementwise_result(triple, args, "3 * (" * only(args).code * ")")
end

matrix_exponential(A::AbstractMatrix) = exp(A)
function RK._jax_function_call(ctx::RK._JaxContext, ::typeof(matrix_exponential),
                               args::Vector{RK._PyVal})
    RK._jax_result(matrix_exponential, args,
                   "jax.scipy.linalg.expm(" * only(args).code * ")")
end

# Types supplied to jax_source select scalar, vector, or matrix inputs.
@kernel mapped(x) = begin
    y = triple(x)
    total = sum(y)
    return y, total
end

# The matrix result must keep its rank for the following matrix-vector product.
@kernel mapped_product(A::Matrix{Float64}, v::Vector{Float64}) = begin
    B = triple(A)
    total = sum(B * v)
    return total
end

@kernel prepared(scale::Float64, x) = begin
    y = triple(x)
    total = scale * sum(y)
    return total
end

@kernel exponential(scale::Float64, A::Matrix{Float64}) = begin
    E = matrix_exponential(A)
    total = scale * sum(E)
    return total
end

end # module

Emit scalar and matrix device calls, and a data-only matrix exponential in host preparation:

julia
ex = JAXTranslationExample
scalar_source = jax_source(ex.mapped; have=(:x,), want=:total, types=(x=Float64,))

"""Generated by ReactiveKernels.jax_source; do not edit."""
import scipy.linalg
import numpy as np
import scipy.special as ssp
from typing import Any

import jax
import jax.numpy as jnp
import jax.scipy.linalg
import jax.scipy.special as jsp
from jax.typing import ArrayLike

jax.config.update("jax_enable_x64", True)

INPUTS = ("scale", "E")
PREPARED = {"E": {"dtype": "float64", "ndim": 2, "ragged": False}}


def prepare_data(A: ArrayLike) -> dict:
    """The functions' data inputs, computed from the raw data once per dataset.

    Pass the data by the names the model reads them; a list of arrays is a ragged
    column. Call the other functions with the result: `f(u, **prepared)`.
    """
    A = np.asarray(A, dtype=np.float64)
    E = scipy.linalg.expm(A)
    return {"E": np.asarray(E, dtype=np.float64)}


def kernel(scale: ArrayLike, **prepared: ArrayLike) -> jax.Array:
    """Compute `total` from the inputs."""
    E = prepared["E"]
    E = jnp.asarray(E)
    total = scale * jnp.sum(E)
    return jnp.asarray(total, dtype=jnp.float64)


def _rk_batched_gradient(density, positions, data):
    return jax.vmap(jax.value_and_grad(lambda p: density(p, **data)))(positions)


def bind_gradient(density, prepared, *, device=None, memory_budget_bytes=None):
    """Bind a batched value-and-gradient to prepared data on one device.

    Call the result with a floating-point array whose leading axis is chains.
    The first call at a shape and dtype runs one feasible layout. An explicit
    gradient.calibrate(positions, repeats=3) measures eligible layouts and
    installs its winner for subsequent calls on this binding. It returns the
    timing rows, winner first (empty without a layout selector). Overlapping
    pilot timings trigger 12 interleaved rounds among the close contenders.

    memory_budget_bytes limits the executable's planned device buffer bytes.
    The device allocator, other live arrays and backend overhead are separate.
    """
    from copy import deepcopy
    from functools import partial
    from operator import index
    from threading import RLock

    if memory_budget_bytes is not None:
        memory_budget_bytes = index(memory_budget_bytes)
        if memory_budget_bytes < 0:
            raise ValueError("memory_budget_bytes must be nonnegative")

    # Calibration and execution must see the same bound values, even if the
    # caller later edits a host array. JAX arrays already have value semantics.
    immutable = {id(x): x for x in jax.tree_util.tree_leaves(prepared) if isinstance(x, jax.Array)}
    data = deepcopy(prepared, immutable)
    measure, layout_variants = None, None
    confirm_layouts = None
    programs = {}
    lock = RLock()

    def signature(positions):
        if not hasattr(positions, "dtype"):
            positions = np.asarray(positions)
        if not positions.shape or positions.shape[0] == 0:
            raise ValueError("positions must have a nonempty leading chain axis")
        dtype = jax.dtypes.canonicalize_dtype(positions.dtype)
        if not jnp.issubdtype(dtype, jnp.floating):
            raise TypeError("positions must have a real floating-point dtype")
        target = device
        if target is None:
            if isinstance(positions, jax.Array):
                devices = positions.devices()
                if len(devices) != 1:
                    raise ValueError("specify a device for sharded positions")
                target = next(iter(devices))
            else:
                # Respect jax.default_device for host positions.
                target = jax.config.jax_default_device
                if target is None or isinstance(target, str):
                    target = jax.local_devices(backend=target)[0]
        return (target, tuple(positions.shape), dtype, getattr(positions, "weak_type", False)), positions

    def compile_program(chosen, key):
        target, shape, dtype, weak = key
        sharding = jax.sharding.SingleDeviceSharding(target)
        function = jax.tree_util.Partial(density)
        batch = jax.jit(_rk_batched_gradient, in_shardings=sharding)
        abstract_positions = jax.ShapeDtypeStruct(shape, dtype, sharding=sharding, weak_type=weak)
        program = batch.lower(function, abstract_positions, chosen).compile()
        if memory_budget_bytes is not None:
            try:
                stats = program.memory_analysis()
            except NotImplementedError as error:
                raise MemoryError("backend cannot estimate gradient buffer bytes") from error
            size = getattr(stats, "total_allocation_bytes", None)
            if size is None or size < 0:
                raise MemoryError("backend did not report planned device buffer bytes")
            if size > memory_budget_bytes:
                raise MemoryError(f"gradient requires {size} planned bytes, budget is {memory_budget_bytes}")
        device_data = jax.device_put(chosen, target)
        return lambda positions: program(function, positions, device_data)

    supplied = ("supplied", None, None, None)

    def alternatives():
        if layout_variants is not None:
            for name, groups, sequential, mode, chosen, _ in layout_variants(data, None):
                yield (name, groups, sequential, mode), chosen

    def candidates():
        yield supplied, data
        for layout, chosen in alternatives():
            if chosen is not data:
                yield layout, chosen

    def gradient(positions):
        key, positions = signature(positions)
        with lock:
            _, program = programs.get(key, (supplied, None))
            if program is None:
                failure = None
                for layout, chosen in candidates():
                    try:
                        program = compile_program(chosen, key)
                        result = jax.block_until_ready(program(jax.device_put(positions, key[0])))
                    except (MemoryError, jax.errors.JaxRuntimeError) as error:
                        if not isinstance(error, MemoryError) and "RESOURCE_EXHAUSTED" not in str(error):
                            raise
                        failure = str(error)
                        program = None
                        continue
                    programs[key] = layout, program
                    return result
                raise MemoryError(f"no gradient layout fit on {key[0]}: {failure}")
        return program(jax.device_put(positions, key[0]))

    def same_as_supplied(chosen):
        # Selectors share the bound model data. Compare only changed layout
        # metadata, including the members and widths of a caller's own groups.
        for name, value in chosen.items():
            original = data.get(name)
            if value is original:
                continue
            if name == "_rk_plate_layout":
                value = {k: v for k, v in value.items() if v is not None}
                original = {k: v for k, v in (original or {}).items() if v is not None}
            leaves, tree = jax.tree_util.tree_flatten(value)
            others, other_tree = jax.tree_util.tree_flatten(original)
            if tree != other_tree or any(a is not b and not np.array_equal(a, b)
                                         for a, b in zip(leaves, others)):
                return False
        return True

    def calibration_candidates(active):
        found = False
        for layout, chosen in alternatives():
            current = same_as_supplied(chosen) if active == supplied else layout == active
            found = found or current
            yield layout, chosen, current
        if not found:
            # A caller can supply a partition outside the default search.
            yield supplied, data, True

    def confirm(finalists, rows, steps):
        confirmed = confirm_layouts(finalists, rows, steps, 12)
        if not confirmed:
            return None
        confirmed.sort(key=lambda k: rows[k]["confirmation_median_seconds"])
        current = next((k for k in confirmed if rows[k]["current"]), None)
        if current is None:
            return confirmed[0], "confirmation"

        baseline = rows[current]["confirmation_samples_seconds"]
        median = rows[current]["confirmation_median_seconds"]
        for k in confirmed:
            if rows[k]["confirmation_median_seconds"] >= median:
                break
            samples = rows[k]["confirmation_samples_seconds"]
            if sum(a < b for a, b in zip(samples, baseline)) >= 10:
                return k, "paired_win"
        return current, "retain_current"

    def select(rows, steps):
        order = sorted(steps, key=lambda k: rows[k]["median_seconds"])
        quartiles = {k: np.percentile(rows[k]["samples_seconds"], (25, 75)) for k in order}
        while order:
            low, high = quartiles[order[0]]
            finalists = [k for k in order if quartiles[k][0] <= high and low <= quartiles[k][1]]
            if len(finalists) == 1:
                return finalists[0], "pilot"

            winner = confirm(finalists, rows, steps)
            if winner is not None:
                return winner
            # Every finalist ran out of memory. Compare the remaining pilots.
            order = [k for k in order if k in steps]
        errors = ", ".join(dict.fromkeys(row["error"] for row in rows.values()))
        raise RuntimeError(f"bind_gradient: no candidate ran on this device: {errors}")

    def calibrate(positions, repeats=3):
        repeats = index(repeats)
        if repeats < 1:
            raise ValueError("repeats must be positive")
        if measure is None:
            gradient(positions)
            return []
        key, positions = signature(positions)

        with lock:
            active, program = programs.get(key, (supplied, None))
            batch = jax.device_put(positions, key[0])
            rows, steps = {}, {}
            for layout, chosen, current in calibration_candidates(active):
                def build():
                    if current and program is not None:
                        return partial(program, batch)
                    bound_data = data if current and active == supplied else chosen
                    executable = compile_program(bound_data, key)
                    return partial(executable, batch)
                step, row = measure(layout, len(positions), build, repeats)
                row.update(current=current, confirmation_samples_seconds=[], confirmation_median_seconds=None)
                rows[layout] = row
                if step is not None:
                    steps[layout] = step
                    row["seconds"] = row["median_seconds"]
                row["fit_seconds"] = row["seconds"]
            winner, reason = select(rows, steps)
            programs[key] = winner, steps[winner].func
            first = rows.pop(winner)
            first["selection_reason"] = reason
            return [first, *sorted(rows.values(), key=lambda r: (r["error"] is not None, r["seconds"]))]

    gradient.calibrate = calibrate
    return gradient

After write("matrix_model.py", host_source), run python examples/jax_translations.py matrix_model.py with a Python that has JAX and SciPy. This consumer checks the result and gradient against SciPy and that preparation returns NumPy arrays:

"""Run with: python examples/jax_translations.py matrix_model.py"""
import importlib.util
import sys

import jax
import numpy as np
from scipy.linalg import expm

spec = importlib.util.spec_from_file_location("matrix_model", sys.argv[1])
model = importlib.util.module_from_spec(spec)
spec.loader.exec_module(model)

A = np.array([[0.0, 0.2], [-0.3, 0.1]])
before = A.copy()
prepared = model.prepare_data(A=A)
assert prepared and all(isinstance(v, np.ndarray) for v in prepared.values())
np.testing.assert_array_equal(A, before)
value = jax.jit(model.kernel)(0.7, **prepared)
gradient = jax.grad(lambda scale: model.kernel(scale, **prepared))(0.7)
np.testing.assert_allclose(value, 0.7 * expm(A).sum(), rtol=1e-12)
np.testing.assert_allclose(gradient, expm(A).sum(), rtol=1e-12)
print("Host preparation and device value/gradient agree with SciPy.")
