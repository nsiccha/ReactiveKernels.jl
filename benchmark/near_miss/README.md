# Near-miss probes

These programs time families of sibling models: one model of a shape the
benchmark suites contain, and neighbours that differ in one respect (another
observation law, another spelling, another data layout). Siblings whose
mathematics has the same cost structure should cost about the same. A large
ratio between two of them marks a fast path that is admitted by one spelled
shape rather than by the property that makes it valid.

`probe_families.jl` times the density and the ordinary Enzyme reverse gradient
of each `@rkppl` model through `prepare_sampler`. `reference.jl` holds
hand-written plain-Julia row loops of some of the same densities, differentiated
by Enzyme with the value returned, as the sampler call returns it. Data are
synthetic and generated by the program.

```sh
julia --startup-file=no --project=<env> benchmark/near_miss/probe_families.jl [families] [rows] [filter]
```

`families` is a string of family letters (default `ABCDGR`), `rows` the number of
observations (default 2000), and `filter` a regular expression over variant
names. The environment needs ReactiveKernelsPPL, ReactiveKernels, Enzyme,
ADTypes and Chairmarks. One line is printed per variant as soon as it is
measured; a variant that fails prints its error instead of a timing.

| Family | Base model | Siblings |
| --- | --- | --- |
| A | `y .~ Normal.(a .+ b .* x, sigma)` | named location, matrix design, data-weighted scale, LogNormal, `@plate` loop, quadratic term, exp link, Student-t, modeled scale, scalar location, crossed and gathered intercepts, gathered intercept beside an authored `hcat` or a separate scan |
| B | `y .~ BernoulliLogit.(a .+ b .* x)` on a discrete covariate | continuous covariate, `Bernoulli.(logistic.(…))`, Poisson, Binomial, negative binomial, `@plate` loop |
| C | `y .~ Normal.(alpha[g] .+ b .* x, sigma)` with rows sorted by group | shuffled rows, Bernoulli-logit, Poisson, Student-t, reference coding, missing group labels |
| D | `y .~ Normal.(exp.(a .+ b .* x), sigma)` | Student-t, LogNormal, Gamma, Weibull, Cauchy, Laplace, Logistic with shared shape or scale |
| G | Poisson cubic trend over 40 rows | Binomial quadratic trend, one effect per row, Poisson, Binomial and Bernoulli-logit over a five-column design matrix |
| R | hand-written loops | Normal, Student-t, Cauchy, Bernoulli-logit, Poisson, gathered Normal |

## First measurement

2000 rows, Julia 1.10.12, Enzyme `dogfood` 0.13.221, ReactiveKernels 0.1.332,
ReactiveKernelsPPL 0.1.237, one thread, on a Linux fleet host under a load of
20 to 50 on 32 logical CPUs. Each family ran in its own process, so compare
rows within a family; ratios across families carry the difference in load.
Times are nanoseconds per row for one value-and-gradient call.

| Variant | Gradient, ns per row | Remark |
| --- | ---: | --- |
| A0 `Normal.(a .+ b .* x, sigma)` | 0.19 | bound least-squares statistics: the cost does not depend on the rows |
| A3 the same with scale `sigma .* w`, `w` data | 7.97 | 42 times A0; weighted least squares has the same statistics |
| A8 Student-t at the same location | 24.1 | one `log1p` per row is inherent; see D1 for the hand loop |
| A9 scale `exp.(c .+ d .* z)` | 15.9 | |
| B0 Bernoulli-logit, covariate with 5 values | 0.07 | duplicate cells: one cell per distinct row |
| B2 Poisson, the same covariate, counts 0 to 6 | 7.11 | 100 times B0; at most 35 distinct rows, not grouped |
| B3 Binomial, the same covariate | 13.7 | 190 times B0; not grouped |
| B4 negative binomial | 67.4 | not grouped; `loggamma` and `digamma` per row |
| B0c Bernoulli-logit, continuous covariate | 9.91 | hand loop 12.5 |
| B5c the same in a `@plate` loop | 49.7 | 5 times B0c |
| C0 gathered Normal, sorted groups | 0.57 | hand loop 1.49 |
| C0s gathered Normal, shuffled groups | 1.21 | hand loop 1.12 |

| D3 Gamma, shared shape | 33.2 | one `exp` per row is inherent |

| D5 to D7 Cauchy, Laplace, Logistic | none | `SurfaceLoweringError: unknown distribution` as a response |

The measured gradient equals the hand loop where a benchmark model has the
shape (Normal, Bernoulli-logit, gathered Normal) and is 3 to 8 times a hand
loop's cost for the sibling laws.

## After the Poisson plate lowering and the one-softplus Binomial kernel

The Poisson-log regression lowers to the summed plate of the other count
laws, and the binomial logit kernel reads one softplus without a branch on
the logit. Same conditions as above, under a load of 18 to 27; nanoseconds
for one value-and-gradient call over all rows.

| Variant | Before | After |
| --- | ---: | ---: |
| B2 Poisson, covariate with 5 values, 2000 rows | 14220 | 289 |
| B2c Poisson, continuous covariate, 2000 rows | 14350 | 10660 |
| G0 Poisson cubic trend, 40 rows | 374 | 330 |
| G2 Poisson cubic trend with one effect per row | 457 | 402 |
| G3 Poisson over a five-column design matrix | 17540 | 16740 |
| G4 Binomial over a five-column design matrix | 34160 | 25630 |
| B3 Binomial, covariate with 5 values | 27449 | 26090 |

B3 is unchanged: the Binomial-logit regression keeps its whole-vector
formula, so its repeated rows are still evaluated one by one. The plate with
the exact kernel equals that formula's value-and-gradient time and runs
repeated rows once (26.0 µs to 0.5 µs), but its density-only call takes 23 to
34 percent longer on a continuous covariate.

## Factor coding and level count

The C1 and C2 probes repeat the four factor spellings with Bernoulli-logit
and Poisson responses. Suffixes `r`, `m`, `h` and `t` select a reference
level, missing labels, an authored two-column matrix and a separate scan.
The `x` sibling binds the same two columns as a matrix. The unsuffixed
model is the full-cover sibling for the reference, missing and scan cases.

`factor_scaling.jl` measures a fresh model from data binding through
`prepare_sampler`, then measures the warm density and ordinary Enzyme value
and gradient. Setup MiB are cumulative Julia allocations. Each law and
spelling first runs with 100 rows and five levels to warm its Julia methods.
The target data have 20,000 rows, sorted by group, with 50, 500 or 5,000
levels. The last two command arguments select laws and spellings.

```sh
julia --startup-file=no --project=<env> benchmark/near_miss/probe_families.jl C 2000 '^(C1|C2)'
julia --startup-file=no --project=<env> benchmark/near_miss/factor_scaling.jl 20000 50,500,5000 normal,bernoulli full,reference,missing,bound_matrix,hcat,scan
```

At 20,000 rows, each cell gives the cost on `8a7f69f42` followed by the
cost with factor gathers on `a9959a24b`. The 5,000-level reference design
previously had 99,980,000 entries. The two revisions ran in separate Julia

### After lowering factor terms to level gathers

The factor reads one effect per observation in all four spellings. For a
partial axis, the coefficient table begins with zero. A covered label
indexes its declared coefficient and an uncovered label indexes the zero.
A separately requested design matrix still contains its contrast columns.

These paired measurements use 2,000 rows, 50 groups and one BLAS thread
on gordito. Each pair is the median of five alternating old and new
Chairmarks runs in the same Julia process. The old and new samplers agreed
on the density and on every gradient coordinate at the same parameter vector.

| Spellings | Bernoulli-logit density (µs) | Bernoulli-logit value + gradient (µs) | Poisson density (µs) | Poisson value + gradient (µs) |
| --- | ---: | ---: | ---: | ---: |
| Full cover | 18.0 → 17.9 | 23.5 → 23.4 | 6.30 → 6.30 | 14.0 → 14.0 |
| Reference level | 21.7 → 17.3 | 30.1 → 23.6 | 13.4 → 6.11 | 24.4 → 13.7 |
| Missing labels | 21.3 → 17.2 | 30.0 → 22.6 | 12.9 → 5.86 | 23.3 → 13.8 |
| Bound two-column matrix | 17.2 → 17.2 | 22.9 → 22.9 | 8.51 → 8.57 | 15.9 → 15.8 |
| Authored two-column matrix | 21.5 → 17.9 | 30.3 → 27.3 | 13.4 → 8.60 | 42.7 → 15.9 |
| Separate scan | 22.1 → 17.8 | 31.1 → 23.5 | 12.9 → 6.35 | 23.8 → 13.5 |

At 20,000 rows and 5,000 levels the reference-coded Normal setup went
from 111 s and 6,042 MiB to 3.29 s and 286 MiB. Its gradient fell from
114 ms to 30.8 µs. For Bernoulli-logit, the gradient fell from 91.6 ms to
325 µs and setup allocations from 2,369 MiB to 258 MiB. Setup time rose
from 1.51 s to 3.06 s in those two Bernoulli-logit runs. They ran in
separate processes on a shared host. The complete observations include
all four variants and both full-cover controls at each level count.
[Scaling measurements](factor_scaling.csv)

The standalone lowering leaves a small-level Normal trade-off. At 20,000
rows and 50 levels the reference-coded gradient went from 2.28 to 4.15 µs.
The old dense design used bound least-squares statistics. The new location
mixes a gathered effect and a shared coefficient, so this measurement runs
its row loop. At 2,000 rows the full-cover A13 gradient took 1.09 µs on
both paths. The A15 model with an authored matrix went from 2.13 to
7.41 µs. Reference coding, missing labels and the separate scan at this
smaller row count improved from 2.28, 2.30 and 2.37 µs to 1.21, 1.24
and 1.05 µs respectively.

### Allocation of the reference-level coefficient table

At 20,000 rows the original gather implementation allocated a new
`vcat(0.0, effects)` on every call. The prepared sampler had a vector cache
for this step, but the concatenation method accepted only vector operands.
Allowing the scalar zero to fill the same cache as the coefficient vector
gave the following results for both reference coding and missing labels.
Normal, Bernoulli-logit and Poisson gave the same allocation counts.

| Levels | Density allocations / bytes, initial gather | Density allocations / bytes, reusable table | Gradient allocations / bytes, initial gather | Gradient allocations / bytes, reusable table |
| ---: | ---: | ---: | ---: | ---: |
| 50 | 2 / 512 | 1 / 16 | 6 / 1,184 | 0 / 0 |
| 5,000 | 3 / 40,064 | 1 / 16 | 8 / 80,288 | 0 / 0 |

The full-cover and scan controls also used 1 allocation of 16 bytes for
`q(u)` and zero for `sampler_value_and_gradient!`. The public density call
returns a boxed `Float64` through its world-age barrier.
