# Near-miss probes

These programs time families of sibling models: one model of a shape the
benchmark suites contain, and neighbours that differ in one respect (another
observation law, another spelling, another data layout). Siblings whose
mathematics has the same cost structure should cost about the same. A large
ratio between two of them marks a fast path that is admitted by one spelled
shape rather than by the property that makes it valid.

`probe_families.jl` times the density and the ordinary Enzyme reverse gradient
of each `@rkppl` model through `prepare_sampler`. `reference.jl` holds
hand-written plain-Julia row loops of some of the same densities, differentiated
by Enzyme with the value returned, as the sampler call returns it. Data are
synthetic and generated by the program.

```sh
julia --startup-file=no --project=<env> benchmark/near_miss/probe_families.jl [families] [rows] [filter]
```

`families` is a string of family letters (default `ABCDGR`), `rows` the number of
observations (default 2000), and `filter` a regular expression over variant
names. The environment needs ReactiveKernelsPPL, ReactiveKernels, Enzyme,
ADTypes, Chairmarks and LogExpFunctions. One line is printed per variant as soon as it is
measured; a variant that fails prints its error instead of a timing.

| Family | Base model | Siblings |
| --- | --- | --- |
| A | `y .~ Normal.(a .+ b .* x, sigma)` | named location, matrix design, data-weighted scale, LogNormal, `@plate` loop, quadratic term, exp link, Student-t, modeled scale, scalar location, crossed and gathered intercepts, gathered intercept beside an authored `hcat` or a separate scan, whole-vector range |
| B | `y .~ BernoulliLogit.(a .+ b .* x)` on a discrete covariate | continuous covariate, `Bernoulli.(logistic.(…))`, Poisson, Binomial, negative binomial, `@plate` loop, named and qualified links, whole-vector range, Poisson exposure |
| C | `y .~ Normal.(alpha[g] .+ b .* x, sigma)` with rows sorted by group | shuffled rows, Bernoulli-logit, Poisson, Student-t, reference coding, missing group labels |
| D | `y .~ Normal.(exp.(a .+ b .* x), sigma)` | Student-t, LogNormal, Gamma, Weibull, Cauchy, Laplace, Logistic with shared shape or scale, plus the equivalent standardized `TDist.(nu)` and `StudentT.(nu, 0, 1)` |
| G | Poisson cubic trend over 40 rows | Binomial quadratic trend, one effect per row, Poisson, Binomial and Bernoulli-logit over a five-column design matrix |
| R | hand-written loops | Normal, Student-t, Cauchy, Laplace, Logistic, Gamma, Weibull, Bernoulli-logit, Poisson, gathered Normal |

An earlier version of this table said that A0 uses the bound least-squares
statistics and that its cost does not depend on the rows. That was wrong. Its
prepared program has no residual kernel (`_ls_rss`) and its value-and-gradient
call takes 361 ns at 2,000 rows, 3,286 ns at 20,000 and 39,590 ns at 200,000
(Julia 1.10.12 build kb8, Enzyme `dogfood` 0.13.221, one process): 0.16 to
0.20 ns per row, the speed of a vectorized row sum.

The measured gradient equals the hand loop where a benchmark model has the
shape (Normal, Bernoulli-logit, gathered Normal) and is 3 to 8 times a hand
loop's cost for the sibling laws.

## Factor coding and level count

The C1 and C2 probes repeat the four factor spellings with Bernoulli-logit
and Poisson responses. Suffixes `r`, `m`, `h` and `t` select a reference
level, missing labels, an authored two-column matrix and a separate scan.
The `x` sibling binds the same two columns as a matrix. The unsuffixed
model is the full-cover sibling for the reference, missing and scan cases.

`factor_scaling.jl` measures a fresh model from data binding through
`prepare_sampler`, then measures the warm density and ordinary Enzyme value
and gradient. Setup MiB are cumulative Julia allocations. Each law and
spelling first runs with 100 rows and five levels to warm its Julia methods.
The target data have 20,000 rows, sorted by group, with 50, 500 or 5,000
levels. The last two command arguments select laws and spellings.

## Which plates the generated reverse takes

`plate_reverse_shapes.jl` prepares ten model shapes at 60 and 2,000 rows with
the opt-in generated reverse of summed plates on and off
(`with_plate_reverse`), both from one plan in one process, and times the two
gradients in alternating rounds. It prints the lengths of the one-pass tapes
the preparation owns (none: every plate runs inline, as with the generated
reverse off) and the gradient time on divided by off.

The generated reverse lets a plate take its one pass below 128 cells, with a
buffer per row or with scalar cotangents only, when a cell holds work that
its value and its slope share. The test for that work named `exp`; a native
program has called the exponential of a number `_native_scalar_exp` since
0.1.371, so no cell met it. 0.1.414 asks the predicate that knows every name
of the exponential. Before: `main` `48106ad6a`, one process. After: the
branch from a fresh build, two processes at once on a host at a load of 62 to
85, both readings given.

| Model | Rows | Tapes before | Tapes after | On / off before | On / off after |
| --- | ---: | --- | --- | ---: | ---: |
| `y .~ Poisson.(exp.(a .+ b .* x))` | 60 | 3 | 3, 3, 3 | 1.03 | 0.39, 0.55 |
| the same | 2,000 | 3 | 3, 3, 3 | 0.99 | 0.35, 0.37 |
| Poisson with a parameter per row, `exp.(a .+ sd .* z)` | 60 | none | 62, 62 | 1.01 | 0.51, 0.71 |
| the same | 2,000 | none | 2002, 2002 | 1.00 | 0.38, 0.44 |
| Poisson with a group effect, `sd .* z[group]`, 10 groups | 60 | 3 | 14, 14, 3 | 0.95 | 0.67, 0.79 |
| the same, 20 groups | 2,000 | 24, 24, 3 | 24, 24, 3 | 0.34 | 0.35, 0.44 |

The other seven shapes own the same tapes before and after, so their programs
did not change: Bernoulli-logit plain (3, 3), with a parameter per row (none)

grouped (3 at 60 rows; 24 and 3 at 2,000); a grouped negative binomial (62 or
2002); a grouped Normal (none at 60 rows, 24 at 2,000). Where `main` gains
with the generated reverse on, their readings stay near `main`'s (0.41 to 0.52
